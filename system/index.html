01 · Modules

What the studio actually does.

01

The passport

The passport holds appearance notes, distinctive-detail fields, per-mode identity settings, capture-device preferences, reference images and an optional vision summary. A separate editable creative canon can describe places, props, habits and tone.

02

Adapters

The application converts structured scene and passport fields into model-specific prompt formats for still images, motion, B-roll, dialogue and editing. It accepts Russian or English scene text and prepares English-language production instructions.

03

The taste layer

The creative system includes three selectable worlds (Diary, Raw, Staged), 24 structured visual techniques and reusable scene packs. These guide stylistic choices; they are not a guarantee that an external model will reproduce a particular aesthetic.

04

The five engines

Five external model families have prompt adapters: Nano Banana Pro (stills), Kling (motion), Seedance (short-form), Veo (scenes and B-roll), Omni Flash (clip revision). The app prepares instructions; model access and rendering remain external.

05

Formats & the feed

Frame, Series, Shoot and Feed formats help creators plan shots, cutaways and post sequences. The application organizes scene instructions rather than publishing content or independently verifying consistent identity across a feed.

06

Quality gates

Prompt review tools, visual-quality controls and a local result journal support iteration. The release also includes built-in code checks; those checks do not measure the real-world success rate of generative models.

07

Export

Shot lists with day markers and an AI-disclosure checklist, bundle export as JSON / TXT, a Series Card as PNG.

08

License & data

The live product uses a license gate. Passports and histories are stored in the browser; the user-provided AI key is stored locally in browser settings. When optional AI tools are enabled, requested scene or image data and the key are sent directly to the selected provider. License and analytics requests also involve network traffic.
