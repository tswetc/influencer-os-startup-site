# Influencer OS — public product site

**Influencer OS** is early-stage browser software for organizing reusable synthetic-character passports, scene intent, and engine-specific instructions for image and video production.

The product includes an optional **Anthropic Claude / Messages API** path for reference interpretation, scene refinement, prompt critique and guided edits. The current AI integration uses a user-provided provider key (BYOK). The product's deterministic adapters assemble engine-specific instructions; the actual media is rendered in external services.

### Scope and transparency

This public repository contains the static startup/product website, **not** the private Influencer OS application source or proprietary character assets. UI screenshots come from the first-party product; character visuals are schematic because original media rights have not been approved for publication.

The application is intended for disclosed synthetic characters and authorized-likeness workflows. No partnership, endorsement or investment by Anthropic is claimed. A managed Claude integration and standardized model evaluations are *proposed*, not currently shipped.

The GitHub Pages domain is the present public site. A separate company email and owned domain are not represented as operational until DNS, TLS and inbox delivery are actually verified.
