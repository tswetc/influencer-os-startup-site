## What is genuinely implemented

A live browser product (v1.23) with reusable character passports, scene and constraint controls, deterministic adapters to multiple image/video engines, and optional Anthropic Claude Messages API integration using the user's own API key. Claude assists reference interpretation, scene reasoning and prompt critique; **Claude is not an image/video renderer**. The proposed next stage includes evaluations and a managed Claude integration. No artificial customer, funding or revenue claims are made.
